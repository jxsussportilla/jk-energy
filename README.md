# JK Energy – Sistema de monitoreo del consumo eléctrico residencial

## Descripción del proyecto

JK Energy es un proyecto académico de Ingeniería de Software desarrollado para proponer una solución de monitoreo del consumo eléctrico en hogares de Bucaramanga, Santander, Colombia.

La propuesta está dirigida a **Energía Hogar Santander S.A.S.**, empresa ficticia del sector energético utilizada como caso de estudio.

El sistema busca facilitar la consulta de mediciones eléctricas, el seguimiento del consumo y la identificación de posibles anomalías mediante alertas.

## Objetivo general

Diseñar una solución de software para gestionar y visualizar información sobre el consumo eléctrico residencial, facilitando su seguimiento y la identificación de anomalías.

## Funcionalidades propuestas

- Registro y administración de usuarios y hogares.
- Gestión de dispositivos de medición.
- Consulta del historial de consumo eléctrico.
- Visualización de información energética.
- Generación y consulta de alertas.
- Administración de tarifas y electrodomésticos.

## Metodología

El proyecto utiliza el Proceso Unificado de Desarrollo de Software, organizado en cuatro fases:

1. Inicio: identificación del problema, alcance y planificación.
2. Elaboración: análisis de requisitos, modelado y arquitectura.
3. Construcción: diseño de prototipos y planificación de la implementación.
4. Transición: documentación, criterios de aceptación y preparación de entregables.

## Tecnologías

- MariaDB: gestión de la base de datos.
- SQL: definición y manipulación de información.
- UML: modelado del sistema.
- BPMN: representación de procesos de negocio.
- GitHub: gestión de versiones y documentación.

## Estado del proyecto

**Prototipo académico y documentación de diseño.**

Actualmente se dispone de documentación, modelos y prototipos. No se presenta el sistema como una aplicación completamente implementada o desplegada.
